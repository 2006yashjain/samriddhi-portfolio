| App | Description |
|---|---|
| **About Me** | Samriddhi's profile, exact bio, education, focus areas, verified achievements, and interests. |

| **Projects** | Empty state cleanly prepared for the repository links that will be supplied in Phase 3. |

| **Chat** | Knowledge-grounded Portfolio Assistant answering questions about Samriddhi's education, skills, achievements, and contact details without hallucination. |
| **Resume** | Structured document preview viewer with verified academics and achievements, plus pending PDF upload notice. |
| **Contact** | Mail-style contact app with direct links for Email, Call, LinkedIn, and GitHub. |
